# Technology Stack OSINT

Passive identification of publicly observable technologies associated with the target organisation's website.

## Objective

Identify publicly available information about the technologies and protocols used by the organisation's website.

## Method

Netcraft was used to review publicly available website technology information.

HTTPS response headers were also reviewed using Kali Linux.

No intrusive testing or exploitation was performed.

## Information Reviewed

- Website technology information
- Site history
- Publicly observable technologies
- HTTPS response headers
- HTTP protocol information

## Findings

Netcraft provided information about the organisation's website and its publicly observable technology environment.

The assessment also identified HTTP/2 through HTTPS response header analysis using Kali Linux.

## Security Considerations

Publicly observable technology information can assist threat actors during reconnaissance by providing information about the technologies and protocols used by a website.

Organisations should regularly review externally observable technology information and keep security configurations and technologies appropriately maintained.

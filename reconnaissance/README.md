# Reconnaissance

This section documents the passive reconnaissance and open-source intelligence (OSINT) activities carried out during the security assessment.

The assessment focused exclusively on publicly available information and did not involve intrusive scanning, exploitation, or interaction with internal systems.

## Activities

- Public website OSINT
- WHOIS reconnaissance
- Public DNS analysis
- Certificate and subdomain checks
- Technology stack identification
- Google Dorking

All activities were conducted within the defined assessment scope and followed a passive reconnaissance approach.
